Machten & n-de machtswortels

Hoofdstuk 5 · Van gehele exponenten naar rationale machten, wortels en de irrationale functie f(x) = n√(g(x))

💡 Het kernidee in één zin

Een macht is herhaald vermenigvuldigen. We breiden het begrip stap voor stap uit: van gehele exponenten, over wortels, naar rationale en zelfs reële exponenten — en telkens blijven dezelfde rekenregels gelden.

Machten
an = a · a · … · a (n factoren). De exponent zegt hoe vaak je het grondtal als factor neemt.
Wortels = omgekeerde machten
n√a zoekt het getal dat tot de n-de macht weer a geeft. Daarom is am/n = n√(am).

5.1 · Machten met gehele exponenten

📐 Definitie

Voor a ∈ ℝ en n ∈ ℕ0:

an = a · a · … · a
(n factoren) — a heet het grondtal, n de exponent
Macht 0
a0 = 1  (a ≠ 0)
elk grondtal (behalve 0) tot de 0 is 1
Negatieve exponent
a−n = 1an  (a ≠ 0)
2−3 = 1/2³ = 1/8
⭐ De rekenregels voor machten

Geldig voor a, b ≠ 0 en m, n ∈ ℤ. Deze blijven later ook gelden voor rationale en reële exponenten.

1 · Product van machten (zelfde grondtal)
am · an = am+n
x3 · x5 = x8
2 · Quotiënt van machten (zelfde grondtal)
aman = am−n
x7 / x2 = x5
3 · Macht van een macht
(am)n = am·n
(x2)4 = x8
4 · Macht van een product
(a · b)n = an · bn
(2x)3 = 8x³
5 · Macht van een quotiënt
(ab)n = anbn
(x/3)2 = x²/9
✎ Voorbeeld — vereenvoudigen met gehele exponenten
Vereenvoudig: a5 · a−2a−4
1
Teller samentrekken: a5 · a−2 = a5+(−2) = a3
2
Delen: a3 / a−4 = a3−(−4) = a7
= a7

5.2 · Vierkantswortels in ℝ

🎯 Definitie van √a

Voor a ≥ 0 is √a het niet-negatieve getal waarvan het kwadraat a is:

√a = b  ⟺  b2 = a  en  b ≥ 0
√a bestaat enkel in ℝ als a ≥ 0
Belangrijk — wortel van een kwadraat
√(a2) = |a|
√((−5)²) = √25 = 5 = |−5|  — dus NIET zomaar a, maar de absolute waarde!
Wortel van een product
√(a·b) = √a · √b  (a, b ≥ 0)
√(4·9) = √4·√9 = 2·3 = 6
Wortel van een quotiënt
√(ab) = √a√b  (a ≥ 0, b > 0)
√(25/16) = 5/4

5.3 · n-de machtswortel van een reëel getal

📐 Definitie

Een n-de machtswortel van a is een getal b waarvoor bn = a (n ∈ ℕ, n ≥ 2):

n√a = b  ⟺  bn = a
n heet de wortelexponent; bij n = 2 schrijven we gewoon √a

Het aantal reële n-de machtswortels hangt af van of n even of oneven is, en van het teken van a:

📊 Hoeveel n-de machtswortels bestaan er?
n  \  a a > 0 a = 0 a < 0
n even 2 wortels: ±n√a 1 wortel: 0 geen reële
n oneven 1 wortel > 0 1 wortel: 0 1 wortel < 0

Voorbeelden: 3√(−8) = −2 (oneven, mag negatief)  ·  4√(−16) bestaat niet in ℝ (even + negatief)  ·  4√16 heeft als reële wortels +2 en −2, maar het symbool 4√16 staat per afspraak voor de positieve waarde 2.

⭐ Eigenschappen van de n-de machtswortel

Voor a, b ≥ 0 (analoog aan de vierkantswortel):

Product
n√(a·b) = n√a · n√b
Quotiënt
n√(ab) = n√an√b
Wortel van wortel
m√(n√a) = m·n√a
Macht onder de wortel
n√(am) = (n√a)m = am/n
de brug naar de rationale exponenten (zie 5.4)

5.4 · Machten met rationale exponenten

🎯 Definitie

Voor a > 0, m ∈ ℤ en n ∈ ℕ0 definiëren we een macht met een breuk als exponent via de wortel:

am/n = n√(am) = (n√a)m
de noemer wordt de wortelexponent, de teller de macht

Speciaal geval (teller 1): a1/n = n√a. Bijvoorbeeld a1/2 = √a en a1/3 = 3√a. Voor a > 0 blijven alle vijf de machtregels uit 5.1 onverkort gelden, óók met breukexponenten.

✎ Voorbeelden — rationale exponenten
Bereken 82/3
1
Schrijf als wortel: 82/3 = (3√8)2
2
3√8 = 2 (want 2³ = 8)
3
22 = 4
82/3 = 4
Schrijf 5√(x3) als macht en vereenvoudig 5√(x3) · x1/5  (x > 0)
1
5√(x3) = x3/5
2
Product van machten: x3/5 · x1/5 = x3/5 + 1/5 = x4/5
= x4/5 = 5√(x4)
Vereenvoudig (163/4)1/3
1
Macht van een macht: exponenten vermenigvuldigen → 16(3/4)·(1/3) = 161/4
2
161/4 = 4√16 = 2 (want 2⁴ = 16)
= 2

5.5 · Machten met reële exponenten

🌍 Uitbreiding naar ℝ

Voor een grondtal a > 0 kunnen we de exponent uitbreiden tot elk reëel getal x, ook irrationale getallen zoals √2 of π. Dit gebeurt via benadering: a√2 ligt tussen a1,4 en a1,5, tussen a1,41 en a1,42, … en convergeert naar één reëel getal.

Besluit
Voor a > 0 en x ∈ ℝ bestaat ax en gelden alle machtregels.
Dit is precies wat de exponentiële functie f(x) = ax mogelijk maakt (zie H7).

5.6 · De n-de machtswortelfunctie & inverse functies

📝 Omkeren van een functie

De n-de machtswortelfunctie is de inverse (omgekeerde) van een machtsfunctie. De wortelfunctie maakt het machtsverheffen ongedaan: bij f(x) = xn hoort de inverse f−1(x) = n√x.

Inverse functie bepalen — werkwijze
1. Vervang f(x) door y  →  2. Verwissel x en y  →  3. Los op naar y  →  4. Schrijf als f−1(x)
De grafiek van f−1 is de spiegeling van die van f om de bissectrice y = x.
📐 Domein van een irrationale functie f(x) = n√(g(x))
Regel
Als n even is: het stuk onder de wortel (de radicand) moet ≥ 0 zijn → los g(x) ≥ 0 op.
Als n oneven is, mag de radicand alle reële waarden aannemen → dom f = ℝ.
✎ Voorbeeld — domein bepalen
Bepaal het domein van f(x) = √(2x − 6)
1
De wortelexponent is 2 (even) → radicand moet ≥ 0: 2x − 6 ≥ 0
2
2x ≥ 6 → x ≥ 3
dom f = [3, +∞[
Bepaal het domein van f(x) = 3√(x − 1)
1
De wortelexponent is 3 (oneven) → geen voorwaarde op de radicand
dom f = ℝ
✎ Voorbeeld — inverse functie bepalen
Bepaal de inverse van f(x) = x3 + 2
1
Schrijf y = x³ + 2
2
Verwissel x en y: x = y³ + 2
3
Los op naar y: y³ = x − 2 → y = 3√(x − 2)
f−1(x) = 3√(x − 2)

Controle: f−1(f(x)) = 3√(x³ + 2 − 2) = 3√(x³) = x. ✔ De inverse maakt f ongedaan.

📝 Spiekbriefje
Machtregels (a, b > 0):
am·an = am+n  ·  am/an = am−n
(am)n = amn
(ab)n = anbn  ·  (a/b)n = an/bn
a0 = 1  ·  a−n = 1/an
Wortels:
√(a²) = |a|  ·  a1/n = n√a
am/n = n√(am)
n even + radicand < 0 → geen reële wortel
domein n√(g(x)): g(x) ≥ 0 als n even
