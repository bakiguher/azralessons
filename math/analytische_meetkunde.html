9.1 Cartesische vergelijking van een rechte
De vergelijking opstellen
Met richtingscoëfficiënt + snijpunt y-as

y = a·x + b
a = rico (helling), (0, b) = snijpunt met y-as.

Met rico a en een punt P(x₁, y₁)

y − y₁ = a·(x − x₁)

Rico uit twee punten A en B

a = (y₂ − y₁) / (x₂ − x₁) (als x₁ ≠ x₂)

Door twee punten A(x₁,y₁), B(x₂,y₂)

y − y₁ = y₂ − y₁x₂ − x₁·(x − x₁)

Algemene (cartesische) vergelijking

Elke vergelijking kun je schrijven als u·x + v·y + w = 0

Bijzondere gevallen
  • Door de oorsprong: y = a·x (geen + b)
  • Horizontale rechte door (s, r): y = r  (rico = 0)
  • Verticale rechte door (s, r): x = s  (rico is onbepaald — geen rico)
Veelgemaakte fout: bij twee punten met dezelfde x (bv. G(−3,−2), H(−3,4)) is de noemer 0 → de rico bestaat niet → het is een verticale rechte x = −3.
9.1.2 Zwaartelijnen van een driehoek
Midden van een lijnstuk [AB]

co(M) = xA + xB2 , yA + yB2

Zwaartelijn

Een rechte door een hoekpunt en het midden van de overstaande zijde. De 3 zwaartelijnen snijden in het zwaartepunt Z.

Vergelijking van een zwaartelijn opstellen

  1. Bereken het midden M van de overstaande zijde (middenformule).
  2. Stel de rechte op door het hoekpunt en M (twee-punten-methode).
9.2 Het vectorvlak
Vrije vector

Bepaald door grootte, richting en zin. Mag je vrij verschuiven: a→ = AB→ = CD→ = …

Gebonden vector

Vast aan een aangrijpingspunt (bv. KL→ met startpunt K).

Puntvector

Vanuit de oorsprong O naar punt P: P→ = OP→.

Eenheidsvectoren

Ex→ en Ey→ hebben grootte 1. Als co(P) = (x, y) dan P→ = x·Ex→ + y·Ey→.

Bewerkingen & coördinaten
  • Som (kop-staart of parallellogram): AB→ + AC→ = AD→
  • Scalair veelvoud: EF→ = r·AB→ (een reëel getal × vector)
  • Coördinaat van een vrije vector: co(AB→) = co(B) − co(A) = (xB − xA, yB − yA)
Norm (lengte) van een vector

||A→|| = √(xA² + yA²)   ·   ||AB→|| = √((xB − xA)² + (yB − yA)²)

9.3 Het inproduct van vectoren
Definitie (inproduct = scalair product = inwendig product)

A→ · B→ = ||A→|| · ||B→|| · cos α   (α = hoek tussen de vectoren)

Het resultaat is een reëel getal, geen vector. Komt o.a. uit arbeid: W = ||F→|| · ||s→|| · cos α (in joule).

Eigenschappen
Evenwijdige vectoren

Zelfde zin (α = 0°): A→ · B→ = ||A→||·||B→||
Tegengestelde zin (α = 180°): A→ · B→ = −||A→||·||B→||

Loodrechte vectoren

α = 90° → cos 90° = 0, dus A→ · B→ = 0.
Omgekeerd: als A→·B→ = 0 dan staan ze loodrecht.

Analytische uitdrukking (met coördinaten)

A→ · B→ = xA·xB + yA·yB

Hoek tussen twee vectoren

cos α = xA·xB + yA·yB√(xA² + yA²) · √(xB² + yB²)  =  A→ · B→||A→|| · ||B→||

Voorbeeld (oef. type): co(A) = (4, 1), co(B) = (2, 3).
A→·B→ = 4·2 + 1·3 = 11  ·  ||A→|| = √(16+1) = √17  ·  ||B→|| = √(4+9) = √13
cos α = 11 / (√17·√13) = 11/√221 ≈ 0,7399 → α ≈ 42°17′
Loodrecht testen (oef. 18): reken gewoon A→·B→ = xAxB + yAyB uit. Is het 0 → loodrecht. Voor co(Q) = (2, −⅓): B(½, 3) en D(⅓, 2) staan loodrecht (= 0), A en C niet.
9.4 Vectoriële & parametrische vergelijkingen

Een rechte beschrijven met een plaatsvector A→ (een punt) en een richtingsvector R→ (de richting). Parameter r ∈ ℝ.

Door de oorsprong (y = a·x)

Vectorieel: (x, y) = r·(xR, yR)
Parametrisch: x = r·xR , y = r·yR

Niet door de oorsprong (y = a·x + b)

Vectorieel: (x, y) = (xA, yA) + r·(xR, yR)
Parametrisch: x = xA + r·xR , y = yA + r·yR

Door twee punten A en B

  1. Plaatsvector = A (een van de punten).
  2. Richtingsvector R→ = AB→ = co(B) − co(A).
  3. Invullen: (x, y) = co(A) + r·(co(B) − co(A)).
Voorbeeld: rechte door A(−3, 2) en B(2, 1).
R→ = co(B) − co(A) = (2−(−3), 1−2) = (5, −1)
Vectorieel: (x, y) = (−3, 2) + r·(5, −1)
Parametrisch: x = −3 + 5r  ;  y = 2 − r
Bijzonder: richtingsvector voor rico a = pq is (q, p). Bv. rico ⅓ → richtingsvector (3, 1). Verticale rechte → richtingsvector (0, 1); horizontale → (1, 0).
9.5 Van parametrisch naar cartesisch

Werkwijze: elimineer de parameter r

  1. Schrijf r vrij uit beide parametervergelijkingen.
  2. Stel de twee uitdrukkingen voor r aan elkaar gelijk.
  3. Werk uit tot y = a·x + b (cartesisch) of u·x + v·y + w = 0 (algemeen).
Voorbeeld: x = −3 + 4r en y = 5 + 3r.
Uit x: r = x + 34  ·  uit y: r = y − 53
Gelijkstellen: x + 34 = y − 53 → 3(x + 3) = 4(y − 5) → y − 5 = ¾·(x + 3)
Bijzondere gevallen: als xR = 0 → vergelijking x = xA (verticaal); als yR = 0 → y = yA (horizontaal).
